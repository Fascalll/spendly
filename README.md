# Spendly

Aplikasi web berbasis **Laravel** untuk pencatatan transaksi, pengelolaan kategori, entri jurnal, serta rekap laporan keuangan.

## Fitur Utama
- **Autentikasi & Profil Pengguna** (login, registrasi, pengaturan profil dan foto profil)
- **Manajemen Transaksi & Kategori**
- **Entri Jurnal & Dashboard Ringkasan**
- **Laporan Keuangan, Export/Import Excel & Layanan Mata Uang**

## Prasyarat Sistem
- **PHP >= 8.4.1**
- **Composer**
- **Node.js & NPM**
- **SQLite** (default pada `.env.example`) atau **MySQL**
